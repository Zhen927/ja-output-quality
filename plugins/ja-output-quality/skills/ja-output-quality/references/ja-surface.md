# 日本語表層目録 — 委譲先、翻訳調の最頻型、顧客向け敬語の型、字形・記号

翻訳調・常套句・論証の規範は既存スキルが詳しい。本ファイルはそこへの委譲と、既存スキルが扱っていない二点（顧客向け敬語の型、字形・記号）を持つ。

| 観点 | 参照先 |

## 2. 翻訳調の最頻型（Lane C が最初に見る5つ）

| 型 | Before | After |
|---|---|---|
| 無生物主語＋他動詞 | この結果は、従来の設定が不適切だったことを示している。 | この結果から、従来の設定が不適切だったと分かる。 |
| 「〜することができる」 | 本機能を使うことで、作業時間を短縮することができます。 | 本機能を使うと、作業時間が短縮できます。 |
| 「〜を行う」の名詞化 | 設定の変更を行い、動作の確認を行った。 | 設定を変更し、動作を確認した。 |
| 主語・代名詞の顕在化 | 私たちはそれを検証し、それは問題ないことを確認した。 | 検証したところ、問題はなかった。 |
| 「〜性」「〜化」の堆積 | 拡張性・可用性・保守性を有する構成。 | ノードを足せば処理量が増え、1台落ちても止まらず、設定は1ファイルで済む構成。 |

判断基準は「有無」ではなく「母語の書き手がその位置でそう書くか」。API仕様書の「〜することができる」は可能表現として正確さを優先して残してよい。

## 3. 顧客向け敬語の型

lint の `double_keigo`、`sasete_itadaku`、`sasete_itadaku_overuse`、`ni_narimasu`、`no_hou`、`cushion_overuse`、`hedge_ending_ja` が対応する。判断は Lane C。

| 型 | 誤り／過剰 | 直し |
|---|---|---|
| 二重敬語 | おっしゃられる、ご覧になられる、拝見させていただく、お伺いさせていただく | おっしゃる、ご覧になる、拝見する、伺う |
| させていただく | ご確認させていただきます、ご提案させていただきます、ご連絡させていただきます | 確認いたします、ご提案します、ご連絡します（相手の許可・恩恵がある場面だけ「させていただく」） |
| 〜になります | 資料になります、担当になります | 資料です、担当です |
| 〜のほう | 資料のほうをお送りします | 資料をお送りします |
| クッション言葉の連打 | 恐れ入りますが、お手数ですが、大変恐縮ですが、を一通に3回以上 | 一通に1回 |
| 確信度の均し | 〜かと存じます、〜と思われます、〜ではないでしょうか、を全文にまぶす | 確認済みは断定、未確認は【要確認】、推定は「〜と推定します（根拠: 〜）」 |
| 御社／貴社 | 話し言葉の御社を文書で使う | 文書は貴社、会話は御社 |
| 重複の結び | 「よろしくお願いいたします」を2回以上 | 末尾に1回 |
| 「ご査収ください」 | 添付がないのに使う | 添付があるときだけ |
| 「〜させていただいております」 | 常態化した謙譲 | 「〜しております」 |
| 「〜いただけますと幸いです」の連打 | 依頼のたびに付ける | 依頼は1通に要点1つ、期限を添える |

customer-qa-style の回答本体（体言止めの箇条書き）は敬語の対象外。敬語が問題になるのはリード文・メール本文・提案書の地の文。

## 4. 字形・記号

lint の `non_jis_kanji`、`nonstandard_punct`、`fullwidth_alnum`、`halfwidth_punct` が対応する。

- 読点は「、」、句点は「。」。「，」「；」は使わない（公用文の一部流儀では「，」を使うが、顧客向け業務文書では「、」に統一）。
- 引用符は「」『』。“”は使わない。
- 全角英数（ＡＢＣ１２３）は半角に。単位・パーセントは半角。
- 範囲は「〜」（全角波ダッシュ）に統一。「~」「～」「-」との混在を避ける。
- 丸数字（①②③）と括弧数字（（１）（２））は文書内で用途を固定する（customer-qa-style では手順に①〜⑤、小論点に（１）（２））。
- 並列の中黒「・」は箇条内では可。地の文の並列は「、」（japanese-tech-writing の規範）。
- JIS（cp932）にない字は疑う。多くは簡体字の混入（关→関、实→実、对→対、经→経、发→発、说→説、术→術、检→検、变→変、单→単、时→時、现→現、应→応、这→この、进→進、过→過、达→達、运→運、请→請、认→認、设→設、语→語、调→調、资→資、质→質、项→項、类→類、组→組、线→線、络→絡、统→統、结→結、络→絡、业→業、东→東、车→車、两→両、严→厳、举→挙、楽 は正当、优→優、传→伝、价→価、备→備）。正当な異体字（𠮷、髙など）も引っかかるので判断は人が行う。

## 5. Lane C チェックリスト

- [ ] 無生物主語＋他動詞、「〜することができる」「〜を行う」「〜において」の密度が低い
- [ ] 主語・代名詞の顕在化なし、「〜性」「〜化」の堆積なし
- [ ] 二重敬語なし、「させていただく」は許可・恩恵の場面だけ
- [ ] 「〜かと存じます」「〜と思われます」が確信度の逃げ場になっていない
- [ ] クッション言葉は一通に1回、結びは1回
- [ ] 貴社／御社、全角英数、範囲記号、丸数字の用途が統一されている
- [ ] 「，」「；」「“”」、JIS外の字なし
