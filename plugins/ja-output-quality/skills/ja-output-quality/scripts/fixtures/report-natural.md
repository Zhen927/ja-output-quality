# 発注ミスは入力の設計で減らせる

発注ミスの大半は手入力から起きている。2026年4月から8月の5か月で発生した発注ミス42件のうち、38件が数量または品番の手入力誤りだった。残る4件は納期の読み違いで、入力とは別の問題になる。

手入力が残っている画面は3つある。うち発注確認画面が最も多く、42件中29件を占めた。この画面は在庫システムから品番を引けるのに、担当者が慣習で手で打っている。理由を聞くと、検索が遅いからだという。検索の応答は実測で平均4.2秒、最長で11秒だった。

対策は検索を速くすることであって、注意喚起ではない。過去2年で注意喚起の掲示は4回出ているが、ミスの件数は減っていない。検索のインデックスを品番の前方一致に張り替えれば、応答は1秒を切る見込みだ。これは開発環境での計測で、本番のデータ量では未検証である【要確認】。

次に着手すべきは、この画面の検索改修とその後1か月のミス件数の追跡だ。残る2画面は件数が少なく、改修の優先度は低い。
