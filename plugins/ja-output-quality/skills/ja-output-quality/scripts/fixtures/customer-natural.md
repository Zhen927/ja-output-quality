１．Entra ID との連携可否
Entra ID を IdP としてサポート。SAML SSO と SCIM によるユーザー・グループの自動プロビジョニングが可能（Enterprise Edition 以上）。
　・SAML＝認証（ログイン）
　・SCIM＝アカウント作成・更新・削除（プロビジョニング）

２．アクセスコントロールの範囲
　・組織単位: Entra ID グループを Snowflake ロールにマッピング可能
　・役職単位: Entra ID で役職別グループを作成し、ロールに割り当て可能
　・ユーザー単位: 個別ユーザーを直接ロールに割り当て可能
　　　SCIM で同期できるのはユーザー属性（名前・メールなど）とグループ情報のみ。
　　　Entra ID の「部署」「役職」属性をそのまま権限条件として使うことは不可
　　　→ グループ化して利用する設計が必要

３．同期のタイミングと所要時間
　・SCIM の同期間隔は Entra ID 側の設定に依存（既定 40 分前後。公式 Doc 上は「最大 40 分」）
　・初回同期は対象ユーザー数に比例。1,000 ユーザー規模で 1〜2 時間程度（弊社検証環境での実測。貴社規模では【要確認】）
　・ネストしたグループの展開可否は公式 Doc に明記なし【要確認】。検証環境での確認を推奨

４．組織レベルで管理する場合の対応イメージ
　（１）Entra ID 側でグループ設計（部署ごと・役職ごと）
　（２）SCIM でグループ同期し、Snowflake ロールにマッピング
　（３）権限付与（グループ→ロール）
　　　（SSO 障害時の緊急ログインを考慮して、管理者のみパスワード認証を残すお客様もいます。）

※ 本回答は Enterprise Edition・シングルテナント構成を想定。Business Critical の場合は Tri-Secret Secure との併用可否を別途整理。
